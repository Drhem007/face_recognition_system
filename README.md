# Edge AI Exam Security & Automated Attendance

A full-stack IoT solution that automates facility security and administrative reporting using Computer Vision.

## ✨ Key Features
* **Biometric Access**: Real-time face recognition using **OpenCV** on a Raspberry Pi.
* **Automated Data Pipeline**: Parses Excel schedules to dynamically set exam timings and authorized student lists.
* **Physical Feedback**: Integrated OLED display for status, Piezo buzzer for verification, and Servo motor for door control.
* **Auto-Reporting**: Generates and uploads final attendance reports (Present/Absent) back to the web app.

## 🛠️ Tech Stack
* **Dashboard**: Next.js / Cloud.
* **Edge Intelligence**: Python / OpenCV / Raspberry Pi.
* **Communication**: Bi-directional API polling and POST requests.
